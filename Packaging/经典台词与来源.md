# 飞行雪绒 1.4.2 · 经典台词

此次只更新独立 App 的文字气泡，以及 Codex 内置自定义宠物的主题简介。没有替换图集、形象、尺寸、动作、声音、hooks 或信任记录。无音频下载、语音合成、联网或提示词读取。

## 台词与场景

- 点击及原有低频日常互动：问候、登台、保护、旅途和骄傲主题，避免立即重复同一句。
- 用户主动飞行：星海主题短句。
- 工作／工具运行：交给我主题短句；共用 60 秒冷却，避免每次工具调用都弹出。
- 完成：骄傲或旅途主题；分别保留 8 秒和 7 秒阅读时间。
- 失败：游戏短句后另起一行显示明确的工具失败提示。
- 权限确认、首次右键菜单提示和本地测试仍使用明确功能文案，不伪装成角色原话或真实事件。
- 日常自动气泡沿用 300 秒冷却；没有新增定时提醒。

## 来源与边界

1. **pride**：采用用户此前指定的完整句子，纠正本次输入中的重复字。官方《寰宇人类注疏：群星交错》角色介绍也使用同一措辞，见[鸣潮官方微博内容在新浪页面中的展示](https://www.sina.cn/news/detail/5327526663555212.html)，2026-01-01 的角色介绍条目。
2. **journey**：来自[鸣潮官方剧情动画《我与你》简介](https://www.bilibili.com/list/1955897084?bvid=BV1NqFnzUEL4&oid=116027081954967)，2026-02-07；采用该简介的“最后这段旅途”完整短句，保留“太好啦”的措辞。
3. **protection**：采用[库洛游戏官方周边品牌发布内容](https://www.sina.cn/news/detail/5327526663555212.html)，2026-08-02，小小远航星手偶展示中的“未来”短句；这条官方文案确认了措辞，不把未查到的具体剧情时间码写成已验证事实。
4. **greeting**：用户早先明确指定的“你能看见我吗？”；本轮未另行确认具体过场时间码。
5. **entrance / flight / working / failed**：来自[爱弥斯语音整理](https://genshin-builds.com/cn/wuthering-waves/characters/aemeath/info)中的共鸣技能三、冲刺一、进战提醒及受击一。该页为第三方游戏语音转录，不标成库洛官方逐字稿。

实际字符与持续时间统一保存在 `Sources/FlyingSnowfluffApp/PetDialogue.swift`，不散落在多个触发点中。本轮只选少量短句，不包含整段剧情或完整语音库。

## Codex 内置宠物

仅更新 `pet.json` 的 `description`；名称、id、图集路径及图片内容均保留。当前客户端自定义宠物接口没有可用的角色台词字段，内置宠物的任务状态提示仍由 Codex 提供。不能把主题简介更新理解为内置气泡已替换。

若宠物设置页缓存旧简介，请刷新自定义宠物列表。无需更换宠物选择、重置信任或重启正在执行任务的 Codex。

## 本机升级与恢复

新版 App 位于 `~/Applications/FlyingSnowfluff.app`，桌面已有 Finder 别名继续使用。隐藏后双击 App 或别名可恢复。

仓库不会上传开发机器上的历史升级备份。完整安装器会在目标机器的 `~/.codex/flying-snowfluff-backups/` 保留被替换的 App 与宠物文件；hooks 合并器会创建 `~/.codex/hooks.json.backup-<timestamp>`。App-only 升级器则由调用者指定独立备份目录，并同时保存可恢复 App 与校验过的 ZIP。

仅供本机私人角色桌宠使用；角色和游戏文字权利归原权利人所有。本机 ad-hoc 签名不等于 Apple Developer ID 公证。
