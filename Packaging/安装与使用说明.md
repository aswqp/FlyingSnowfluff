# 飞行雪绒·爱弥斯

这是一个仅在本机运行的 macOS 桌宠。它不会联网、录音、发送提示词或采集遥测。

## 1.4.4 待机分层接缝修复

修复待机呼吸和摆翼过程中，头发与翼根在少数极值帧短暂露出桌面背景、看起来像白色束线割裂的问题。根因是可转动部件与身体采用零重叠的硬边分层；旋转后原接缝会短暂张开。本版在接缝内侧保留 8 个高清素材像素（Retina 默认显示约 4 pt）的同色底层重叠，使运动极值仍由角色本身的原色覆盖。

修复没有加入模糊、描边或白色填充，也没有降低头发和翅膀的摆动幅度。静态人物、尺寸、目镜表情、台词、飞行、设置、hooks 和 Codex 内置宠物均保持不变；本次只更新独立 App 的待机分层素材。

## 1.4.3 贴近人物的主题气泡

气泡改为粉白—冰蓝浅渐变、青蓝—暖粉细边、深莓紫文字和小尾尖；短句自动收窄，长句保持 14 pt 两行排版。定位依据实际素材轮廓，不再把头顶透明留白当成人物顶部。默认尺寸下，尾尖距离待机头环约 18 pt，并给挥手等姿势预留至少 8 pt 的静态间距。气泡锚点固定，不跟随眨眼和转头来回跳动，也不会拦截桌面点击。

本次仅更新独立 App 的气泡，不修改角色素材、尺寸、动画、台词、hooks 或 Codex 内置宠物。升级前备份旧版 App；既有桌面 Finder 别名仍指向同一个应用，隐藏后双击即可恢复。

## 1.4.2 经典台词更新

独立 App 的点击、工作、飞行与完成气泡改为少量爱弥斯经典短句，并加入用户指定的骄傲主题剧情台词。长句保留 7–8 秒，气泡仍采用原有两行布局；权限、工具失败与本地测试保留明确状态文字。工作和工具提示共用 60 秒冷却，自动日常气泡沿用 300 秒冷却。声音仍关闭，外观、尺寸、动画和 hooks 均不变。

Codex 自定义宠物同步的只是主题简介，沿用已经安装的 1.4.1 高清动效图集；内置任务状态提示不能通过该宠物包自定义。新版 Codex Pet ZIP 与独立 App 是分开的交付物，刷新宠物列表即可读取新简介，不需要重新授权 hooks。台词出处和恢复说明见同包的《经典台词与来源.md》。

## 1.4.1 动效升级

1.4.1 是桌面 App 自身的动效与交互升级。升级 App 不会改写现有 Codex hooks，也不会改变或代替 Codex `/hooks` 页面的本机信任确认；已经安装的旧版 Codex 内嵌 skin 保持原样，本轮不会自动迁移为新的桌面动效素材。

根据实际预览反馈，常驻工作姿势已改为自然放松的双手，不再反复切换举爪姿势。空闲时偶尔短暂微笑、双眨眼和左右探头；工作时也保留这些微动作，但节奏放缓，不触发自动巡游或气泡。“安静陪伴”会停止自动探头、保留基础呼吸和眨眼。默认仍为 208 pt 和原来的四档尺寸；素材按旧版人物实际可见高度校准。悬停目镜跟随层使用同一缩放锚点，不会再叠到额头。

本版新增 7 种日常小动作、动作预览，以及“安静陪伴”开关。日常或待机时，小动作会在 60–150 秒的随机间隔内出现；工作、工具运行、等待输入、故障或完成状态下不会自动巡游或触发大型动作。“安静陪伴”开启后，也会抑制日常大型动作和自动飞行。鼠标悬停时不会巡游或触发动作，但角色仍保持轻微呼吸感，而不是完全冻结。

飞行优先以 60 Hz 更新；系统处于低电量模式时自动降为 30 Hz。菜单中的“减少动态效果”仍可进一步抑制自动动态行为。

## 本机完整安装（`install_local.sh`）

从源码克隆后，先在项目根目录运行 `zsh scripts/build_release.sh`，确认 `dist/` 已生成并通过校验，再运行 `zsh scripts/install_local.sh`。完整安装需要 PATH 中可用的 Node.js 22+（或显式设置 `NODE_BIN`），用于安全合并 hooks JSON。安装流程会复制并校验 App、安装 Codex 宠物资源、合并本地 hooks、注册 Finder 入口，并创建桌面 Finder 别名和桌面分享包。安装完成后，仍须在 Codex 的 `/hooks` 页面逐项核对并信任实际列出的本地处理器；安装程序不会伪造任何信任记录。

## 已安装位置

以下位置仅适用于已在本机完成 `install_local.sh` 完整安装的用户：

- 桌宠应用：`~/Applications/FlyingSnowfluff.app`
- Codex 自定义宠物：`~/.codex/pets/flying-snowfluff-aemeath/`
- Codex 生命周期 hooks：`~/.codex/hooks.json`

完整安装会将替换前的 App 以及平铺的宠物资源文件备份到 `~/.codex/flying-snowfluff-backups/`，再合并 hooks；不会删除其他 hooks。hooks 合并器另行创建 `~/.codex/hooks.json.backup-<timestamp>`。

## 接收者仅解压分享 ZIP

分享 ZIP 面向其他 Apple Silicon、macOS 15+ 用户。分享给他人时，必须同时发送 `飞行雪绒·爱弥斯-分享包-macOS-arm64.zip` 与同名 `.zip.sha256`。SHA-256 仅验证传输完整性，不能验证发布者身份；本包的 ad-hoc 本机签名不证明发布者身份，也不等于 Apple Developer ID 公证。接收者先用 ZIP 同目录的 `.sha256` 校验压缩包本身，并在解压后用 `SHA256SUMS.txt` 校验内容；随后可在解压目录中右键 `FlyingSnowfluff.app` 并选择“打开”，也可自行将 `FlyingSnowfluff.app` 移动到 `~/Applications`。分享包未做 Apple Developer ID 公证，若首次打开被拦截，请继续使用 Finder 右键「打开」。

仅解压分享 ZIP 不会自动创建桌面 Finder 别名、安装 Codex 宠物、写入 hooks 或启用登录项。若接收者需要 Codex 联动，必须自行运行可信的本机安装流程，并按本说明和自己的 `/hooks` 页面核对每个处理器；不得伪造或转移其他机器上的信任记录。

## Finder 与桌面启动

- 对已完整安装的本机，唯一真实 App 位于 `~/Applications/FlyingSnowfluff.app`，访达和 Spotlight 均可找到。
- 本机桌面的“飞行雪绒·爱弥斯”是 Finder 别名，不是第二份 App；请勿改成复制品。
- 桌宠隐藏后，双击真实 App 或本机桌面别名即可恢复显示；反复双击不会启动多个实例。
- 本机完整安装创建的桌面 `飞行雪绒·爱弥斯-分享包-macOS-arm64.zip` 可发送给其他 Apple Silicon、macOS 15+ 用户；接收者的使用方式见「接收者仅解压分享 ZIP」。

## 桌面操作

- 单击：随机卖萌并显示一句气泡。
- 双击：立即沿屏幕安全区域内的曲线飞行。
- 拖拽：自由摆放；拖到另一块显示器后，那里会成为新的巡游屏幕。
- 悬停：暂停逐帧动画，并让电子目镜看向鼠标。
- 动作预览：从设置菜单预览挥手、害羞、歪头、整理目镜、小憩、摇摆和探头；预览是本地交互，不代表 Codex 状态事件。
- 右键或 Control+单击：打开与菜单栏完全相同的设置菜单；菜单栏图标被其他项目遮挡时也能使用。
- 菜单栏 ✨：暂停、隐藏、立即飞行、动作预览、调整尺寸、切换跨屏、安静陪伴、登录启动、减少动态效果和退出。

默认使用 208 pt 均衡尺寸并严格保持 192:208 原生比例；还可切换 176、256、320 pt。Retina 屏幕优先使用 2× 高清图集，素材异常时会自动回退兼容图集，不影响启动。

默认每 2–5 分钟飞行一次，每 60–150 秒随机出现一次日常小动作。默认关闭安静陪伴、保持静音、当前屏幕巡游并在登录时启动。工作与工具状态始终采用安静策略，不会自动巡游；无需额外开启“安静陪伴”。

从 1.0 升级时，旧尺寸会自动映射到新的四档尺寸；暂停、跨屏、减少动态效果、登录启动和静音选择均会保留。“安静陪伴”作为 1.4.0 新设置默认关闭。此设置迁移只作用于桌面 App，不会迁移或替换现有 Codex 内嵌 skin。

## Codex 联动

1. 本节只适用于已完成本机完整安装的用户。`~/.codex/hooks.json` 配置 6 个只调用本地 `flyingsnowfluffctl` 的命令：`UserPromptSubmit`、`PreToolUse`、`PermissionRequest`、`PostToolUse`、`Stop` 和 `SessionEnd`。当前 Codex 客户端的 `/hooks` 页面可能只列出 5 个可执行处理器；请逐项核对并信任页面列出的每个 `flyingsnowfluffctl` 处理器。即使页面未列出 `SessionEnd`，也不要仅因此从配置中删除它。
2. 完成当前任务后重启 Codex Desktop，并新建一个测试任务，让长时间运行的 app-server 重新加载 hooks。
3. 右键桌宠可查看“Codex 联动”实时状态和最近事件时间；“测试联动显示（本地）”只测试动画，不会伪装成真实 Codex 事件。
4. 如果 Codex 宠物列表尚未刷新，打开“设置 → Pets → Custom pets”，点击 “Refresh custom pets”。
5. 原生 Codex Pet 可按需选用；桌面版与 Codex 内嵌版互不依赖。

状态映射为：提交请求 → 工作、工具前 → 扫描、权限请求 → 等待、工具后 → 工作或故障、停止 → 完成、会话结束 → 待机。若当前客户端未列出或执行 `SessionEnd`，不要删除该配置；完成、故障和工作/扫描状态仍会按各自 TTL 自动回到日常模式，等待状态会在下一次工作事件到来时解除。

辅助程序只通过权限 `0600` 的 `/private/tmp/flying-snowfluff-$UID.sock` 发送版本化 JSON，字段限于事件、会话/回合 ID 和时间。桌宠未运行、输入无效或 socket 不存在时会静默放行，不阻塞 Codex。

## 分享包校验

分享 ZIP 同目录的 `.sha256` 校验压缩包本身；解压后的 `SHA256SUMS.txt` 校验 App 关键文件和安装说明。Codex Hooks 的信任只对本机有效；接收者若要另行完成可信安装，必须在自己的 `/hooks` 页面核对并确认。

## 手动恢复或卸载

本机完整安装后，先从菜单栏退出桌宠。需要恢复时，可从 `~/.codex/flying-snowfluff-backups/` 取回安装前的 App，以及平铺备份的 `pet.json` 和 `spritesheet.webp`；这里并不保存整个宠物目录。hooks 合并器的原始配置备份位于 `~/.codex/hooks.json.backup-<timestamp>`；不要将 hooks 合并器备份误认为位于 `flying-snowfluff-backups`。若只想停用联动，可在 `/hooks` 中禁用对应命令；不要直接覆盖整个 `hooks.json`，以免影响其他 hooks。
