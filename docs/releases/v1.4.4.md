# 飞行雪绒·爱弥斯 v1.4.4

这是 Apple Silicon、macOS 15+ 的私人非商业桌宠发布包。

## 本版内容

- 修复待机摆动极值帧中头发和机械翼连接处短暂露出桌面背景的问题；
- 保留原有角色形象、尺寸、目镜表情、摆动幅度、台词、飞行和 hooks；
- 保留 60 Hz 飞行，同时使用 Core Animation 图层位移降低逐帧窗口管理开销；
- 提供独立 App、可分享自校验包和 Codex Pet 包；
- 仓库构建改为路径无关，Release 默认输出到项目内 `dist/`。

## 建议下载

普通使用者下载：

- `飞行雪绒·爱弥斯-分享包-macOS-arm64.zip`
- `飞行雪绒·爱弥斯-分享包-macOS-arm64.zip.sha256`

校验：

```zsh
shasum -a 256 -c 飞行雪绒·爱弥斯-分享包-macOS-arm64.zip.sha256
```

解压后在 Finder 中右键 `FlyingSnowfluff.app` 并选择“打开”。本包使用 ad-hoc 签名，没有 Apple Developer ID 公证。
